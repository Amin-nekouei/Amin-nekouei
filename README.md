## ⭐ Featured project: ScholarBridge

**A bilingual (Persian/English) marketplace that connects clients who need research done with vetted researchers.** Built with Django and deployed on Render with PostgreSQL.

[**▶ Live demo**](https://researchdesk-beta.onrender.com/en/) · [**Screenshots & architecture**](https://github.com/Amin-nekouei/scholarbridge)

- Three roles (client, researcher, admin) with every permission enforced on the server
- A single state machine controls the whole project lifecycle, with a full audit trail
- Protected file downloads, in-project messaging, ratings and in-app notifications
- Complete RTL/LTR internationalization, automated tests and infrastructure-as-code deployment

> Try it with `client1` / `demo1234`. The first load can take up to a minute on the free hosting tier.
